40 p: 13  방어 목표 / 위협 모델
41 tbl: 기존 DLLGuard는 첫 렌더 후 DLL 목록을 baseline으로 저장하고 약 1초마다 새 경로를 비교한다. 허용되지 않은 DLL이면 경고창을 표시하고, 창이 닫히면 ExitProcess(1)로 종료한다. 로드 자체를 선제 차단하는 방식은 아니다. | 핵심 한계는 검사 함수도 같은 프로세스에서 패치할 수 있다는 점이다. Dll2의 실제 소스는 Dll2/Dll2/dllmain.cpp이며 DetectNewModules(RVA 0xEF90)의 원본 호출을 생략한다. 기존 CRC 범위는 이 함수와 SpawnProjectile 진입점을 포함하지 않는다. [IntegrityGuard.cpp·dllmain.cpp]

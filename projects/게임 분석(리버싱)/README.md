# 게임 분석(리버싱)

1.내가 만든 파이썬 파일을 실제로 실행하려면 code폴더의 각 날짜별 폴더가 있는데 daily_memo 폴더의 날짜별pdf나 설명을 본다
2.그 날 배운 내용과 관련된 코드를 날짜에 맞춰 파이썬 파일을 저장되어 있다.
3. 이를 복사해 source/dist폴더에 그 코드를 복사 붙여넣기하면 실제 사용해 볼 수 있다
4.게임v2분석은 8.2 - 8.12동안 진행한 프로젝트로 이전의 분석하던 게임에서 약간 변형된 조금 더 고난이도의 리버싱용 게임을 처음부터 끝까지 리버싱을 해서 핵을 만드는 프로젝트를 진행했다.
또 다른 주의사항은 먼저 server.exe를 실행한 상태에서 파이썬 파일을 실행해야 한다는 점이다.


실행 경로는 이 README가 있는 폴더 기준입니다. source/dist/server.exe 등 일부 실행 자료는 Git에서 제외되어 있습니다. 새로 내려받은 환경에서의 확보 방법은 **확인 필요**입니다.

PENGUIN RIFT
간단한 게임 안내
========================================

1. 게임 소개
----------------------------------------
Penguin Rift는 펭귄을 조작하여 스테이지를 진행하는
2D 플랫폼 액션 게임입니다.

게임을 시작하면 먼저 플레이어 이름을 입력합니다.
입력한 이름은 게임 기록을 구분하는 데 사용됩니다.


2. 실행 방법
----------------------------------------
PenguinRift.exe와 SDL2.dll을 같은 폴더에 둔 뒤
PenguinRift.exe를 실행하십시오.


3. 기본 조작
----------------------------------------
이동
  A / 왼쪽 방향키   : 왼쪽 이동
  D / 오른쪽 방향키 : 오른쪽 이동

점프
  Space / 위쪽 방향키

공격
  Z / X : 얼음 공격

기타
  R   : 게임을 처음부터 다시 시작
  F7  : 기록 확인
  Esc : 게임 종료


4. 게임 진행
----------------------------------------
각 스테이지에 등장하는 적을 모두 처치하면
다음 스테이지로 진행합니다.

적에게 얼음 공격을 맞히면 적을 얼릴 수 있습니다.
얼어붙은 적에게 다시 공격하거나 빠르게 충돌하면
적을 처치할 수 있습니다.

얼지 않은 적과 직접 충돌하거나 화면 아래로 떨어지면
목숨을 잃습니다.

맵에 있는 얼음 결정을 획득하거나 적을 처치하면
점수를 얻을 수 있습니다.


5. 화면 정보
----------------------------------------
게임 화면에는 다음 정보가 표시됩니다.

  PLAYER : 현재 플레이어 이름
  SCORE  : 현재 점수
  LEVEL  : 현재 스테이지
  LIVES  : 남은 목숨
  ICE    : 남아 있는 적의 수
  TIME   : 현재 플레이 시간

R 키로 게임을 다시 시작하면 플레이 시간도
00:00.000부터 다시 측정됩니다.


6. 기록
----------------------------------------
게임의 기록 조건을 만족하여 완료하면
플레이어 이름과 완료 시간이 로컬 기록 파일에 저장됩니다.

F7 키를 누르면 기록 확인 화면을 열 수 있습니다.
기록 파일은 게임 실행 폴더에 암호화된 형태로 저장됩니다.


7. 문제 해결
----------------------------------------
게임이 실행되지 않는 경우 PenguinRift.exe와 SDL2.dll이
같은 폴더에 있는지 확인하십시오.

키 입력이 되지 않는 경우 게임 창을 클릭하여
입력 포커스를 맞춘 뒤 다시 시도하십시오.

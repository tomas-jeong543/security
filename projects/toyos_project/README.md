# Toy OS

x86 부팅 과정과 보호 모드 실행 환경을 다루는 Assembly 실습입니다.

## 목표와 구현 범위

`boot11.asm`에서 BIOS를 이용한 섹터 로딩, GDT 설정, 보호 모드 전환, 스택 초기화, VGA 텍스트 출력 및 명령 문자열 검사 코드를 확인할 수 있습니다. 진입 흐름에서는 고정된 문자열로 검사 함수를 호출합니다. 대화형 셸 완성 여부와 실행 결과는 확인 필요입니다.

## 자료 안내

- [boot11.asm](boot11.asm): 구현 범위를 살펴볼 소스. 최종본 여부는 확인 필요.
- `boot.asm`부터 `boot11.asm`: 단계별 소스. 버전별 변경점은 TODO.
- `.bin`, `.img`: 기존 바이너리와 부팅 이미지. 소스와의 일치 여부는 확인 필요.
- [toy_os.docx](toy_os.docx): 기존 프로젝트 문서.
- [QEMU 실행 메모](QEMU_내용.txt): NASM 및 QEMU 명령 기록.

## 작성 범위와 결과

Assembly 실습 코드와 생성물을 구분해 보관합니다. 직접 작성한 부분, 제공받은 실습 코드, 참고 자료의 범위는 **확인 필요**입니다. 코드에서 확인되는 학습 주제는 메모리 배치, 세그먼트·스택 초기화와 모드 전환입니다. 개인 기여, 실행 화면, 개인 회고는 **TODO**입니다.

## 실행 환경

기존 메모는 NASM, QEMU 및 Windows CMD의 `copy /b`를 사용합니다. 프로젝트 폴더를 작업 디렉터리로 삼아 메모를 참고하십시오. 도구 버전과 재현 검증은 TODO이며, 기존 `.bin`과 `.img`를 덮어쓰지 않도록 재빌드 시 별도 출력 경로를 사용하십시오.

# War Game / Reversing

리버싱 문제의 풀이 스크립트와 분석 기록을 모은 디렉터리입니다. 문제별 플랫폼, 출처, 완료 상태는 확인 필요입니다.

## 목표와 수행 내용

데이터 변환을 코드로 재현하고 정적 분석 결과를 실행 상태와 연결하는 연습입니다. [Reverse_basic1.py](Reverse_basic1.py)는 정수 배열을 ASCII 문자열로 복원합니다. [rev_randzz 메모](rev_randzz/rev_rand.txt)는 IDA 주소와 런타임 주소의 대응, pwndbg에서 중단점과 레지스터 값을 다루는 절차를 기록합니다.

## 작성 코드와 분석 대상

Python 파일은 풀이 코드로 분류합니다. 파일별 직접 작성 범위와 참고한 코드는 확인 필요입니다. `rev_randzz/chall`, `encrypted` 등은 분석 관련 파일이며 정확한 출처와 역할을 확인해야 합니다. `.i64`는 IDA 분석 작업 파일로 원본 소스와 구분합니다. 복원·재구성 코드에 해당하는 풀이가 있다면 문제별로 표시하는 작업은 TODO입니다.

## 배운 점과 재현 TODO

기존 코드·메모에서 확인되는 학습 주제는 문자열 복원, 정적·동적 주소 대응, 분기 조건을 검토하기 위한 실행 상태 조작입니다. 개인 회고는 TODO입니다.

- 문제별 Python 및 분석 도구 버전, 실행 명령, 입력 파일과 기대 결과 기록.
- 문제 출처, 분석 대상 파일명, 직접 작성 범위, 풀이 완료 상태 명시.
- 현재 환경에 종속적인 메모의 주소값과 실행 조건 설명.
